# AIsle Assets

Các thư mục con phản ánh presentation architecture trong kế hoạch chính thức. Hiện tại chúng chỉ là ranh giới module; chưa chứa UI/UX hoặc business logic.

- `Bootstrap`: composition root và startup sau này.
- `Presentation`: presentation adapters sau này.
- `Editor`: map/layout editor sau này.
- `Rendering`: rendering infrastructure sau này.
- `Spine`: Spine integration sau này.
- `Replay`: replay presentation sau này.
- `Dashboard`: analytics dashboard sau này.
- `RuntimeBridge`: cầu nối Unity với core độc lập sau này.
